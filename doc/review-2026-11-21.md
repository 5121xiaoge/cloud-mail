## 二、中危

6. 登录防爆破基于 KV：最终一致、非原子，并发请求可绕过计数 → 用 Workers Rate Limiting 绑定或 Durable Object。`getIp` 回退到 `X-Forwarded-For` 可伪造（Workers 上 `CF-Connecting-IP` 必有，可去掉回退）。
7. 用户被物理删除（`physicsDelete`）后未清除 KV 会话 `AUTH_INFO`，旧 token 在 30 天内仍能通过鉴权。
8. 自助修改密码（`resetPassword`）不校验旧密码、也不吊销其它设备会话。
9. `public/emailList` 的 `size` 无上限，可一次拉取全库，易超出 Workers CPU/内存限制；`num/size` 未校验 NaN。
10. `settingService.set` 直接 `set({...params})`，无字段白名单；`setBackground` 不校验文件类型（SVG 可内联执行），且先删旧背景再写新背景，写入失败会丢失背景。
11. `websiteConfig`（公开接口，每次打开页面都会调用）每次都查询 D1 的 IP 校验记录与存储类型，无缓存，消耗 D1 配额。
12. 定时任务串行 `await`，任一步抛错后续任务全部不执行 → 各步骤独立 `try/catch` 或 `Promise.allSettled`。

## 三、逻辑缺陷

13. `emailService.read` 的更新语句既没有 `await` 也没有 `.run()`，Drizzle 查询很可能根本不会执行（“标记已读”可能不生效，需验证）。
14. `email/delete`、`user/delete`、`allEmail` 等对 `emailIds / userIds` 缺少参数校验，缺参时 `undefined.split` 直接 500。
15. `email/list` 中 `accountService.selectById` 返回空时访问 `accountRow.allReceive` 报 500。
16. 前端 axios：未设置 `timeout`（`ECONNABORTED` 分支永远不会触发），该分支里还有一个 `ElMessage.error('')` 会弹出空提示；无 token 时请求头发送字符串 `"null"`。
17. `hono/webs.js` 重复 `import '../api/user-api'`。

## 四、性能与体验

18. `index.html` 全局加载 Google Fonts（国内常被墙或很慢，阻塞渲染）与 Turnstile 脚本（未开启人机验证也会加载）→ 字体自托管或用系统字体；Turnstile 改为注册时按需动态加载。
19. 路由进入登录页前会等待背景图最多 3 秒（`router/index.js#loadBackground`），首屏偏慢 → 先渲染页面，背景图加载完成后渐显。

Token 存 `localStorage`、无 CSP、i18n 中间件并发串语言、`wrangler.toml` 含真实 D1/KV ID、批量导入 PBKDF2 CPU 压力 —— 详见 `optimization-review.md` 第三节。其中第 1、2 项 XSS 修复后，localStorage 风险会显著降低。
