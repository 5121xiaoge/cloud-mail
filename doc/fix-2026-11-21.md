# Cloud Mail 修复与优化记录（2026-11-21 第三轮）

对应审查清单：`review-2026-11-21.md`。本轮已全部处理，未能在本机编译运行，请部署前执行 `pnpm install && pnpm build` 并按文末清单验证。

## 一、超级管理员单用户模式（默认开启）

- 新增 `security/admin-mode.js`，环境变量 `admin_only` 默认视为 `true`。
- 只有 `admin`（超级管理员邮箱）可以登录；其他账号登录统一提示“邮箱或密码错误”（不暴露账号是否存在）。
- 非管理员的历史登录会话在下一次请求时自动失效。
- `/register`、`/oauth/linuxDo/login`、`/oauth/bindUser` 在服务端直接拒绝；`websiteConfig` 强制返回注册关闭、LinuxDo 关闭。
- 后台“系统设置 → 网站注册”开关被锁定；保存设置时服务端也会强制 `register = 关闭`。
- 未配置 `admin` 变量时登录返回明确错误，避免“谁都登不上”却不知道原因。
- 如需恢复多用户：`wrangler.toml` 的 `[vars]` 中设置 `admin_only = false`。

## 二、登录页

- 移除注册表单、注册 Tab、LinuxDo 登录、绑定邮箱弹窗、人机验证、密码强度等相关代码和样式。
- 去除所有 “Cloudflare” 文字：品牌区描述、底部安全标识、页面 `meta description`。
- 字体改为系统字体（`--cm-font-family`）。
- 自定义背景图不再阻塞页面渲染，加载期间显示深蓝底色。

## 四、安全修复

### 高危
1. **Telegram 邮件查看页 XSS**：服务端新增 `utils/html-sanitize.js` 清洗邮件 HTML（删除脚本/iframe/表单/SVG 等标签、事件属性、危险链接）；页面不再包含任何脚本，并加 `CSP script-src 'none'`；纯文本邮件改为转义输出；查看令牌 30 天过期；缓存改为 `private, no-store`。
2. **附件/内嵌图片 XSS**：统一安全响应头 `fileUtils.safeObjHeaders`（KV / R2 / S3 三种存储都生效）——只有 PNG/JPEG/GIF/WebP/BMP/AVIF 可内联，其余一律强制下载；加 `nosniff` 和 `CSP sandbox`；文件名改为 RFC 5987 编码，中文或含分号的文件名不再破坏响应头。
3. **越权**：改密码、改状态、改角色、删除用户、删除用户邮箱等管理操作不能作用于超级管理员（超管本人操作除外）。
4. **密码哈希泄露**：`/user/list` 不再返回 `password`、`salt`。
5. **初始化入口**：支持独立的 `init_secret`；常量时间比较；失败计数锁定；`init_disabled = true` 可彻底关闭；响应 `no-store`、`no-referrer`。

### 中危
6. 登录 IP 不再信任可伪造的 `X-Forwarded-For`；支持可选的 Workers Rate Limiting 绑定 `login_limiter`（原子计数）。
7. 物理删除用户后立即清除其 KV 会话。
8. 自助修改密码必须输入原密码，修改后注销其它设备的会话（前端设置页已增加“原密码”输入框）。
9. `public/emailList` 单页最多 100 条；分页参数做 NaN 校验。`public/genToken` 加入防暴力破解计数，且只允许超级管理员。
10. `/setting/set` 只接受 setting 表中存在的字段；背景图只允许 PNG/JPEG/WebP/GIF/AVIF 或 https 链接（禁止 SVG）；改为先上传新背景再删除旧背景。
11. i18n 改为按请求隔离语言（`AsyncLocalStorage`），并发请求不再串语言。**需要 `compatibility_flags = ["nodejs_als"]`，四个 wrangler 配置文件均已添加。**
12. 定时任务每步独立 `try/catch`，一步失败不影响后续。
13. 前端增加全站 CSP、HSTS、COOP 响应头（`public/_headers`）。
14. Telegram 消息模板补充 `&` 转义。

### 逻辑缺陷
15. “标记已读”补上 `.run()`，原来更新语句不会执行。
16. 新增 `utils/param-utils.js`，邮件删除、用户删除、账号删除等接口统一校验 ID 列表，缺参不再 500。
17. `email/list`、`email/latest` 在账号不存在或不属于当前用户时返回明确错误。
18. 账号重命名、置顶等接口补充空值校验。
19. axios 设置 60 秒超时；删除超时分支里多余的空 `ElMessage.error('')`；无 token 时不再发送字符串 `"null"`；响应拦截器避免 reject 后再 resolve。
20. 删除 `webs.js` 中重复的 `user-api` 导入。

## 五、新增 / 变更的配置项（wrangler.toml）

```
compatibility_flags = ["nodejs_als"]   # 必需
#admin_only = true                     # 默认开启，设为 false 恢复多用户
#init_secret = ""                      # 独立初始化密钥
#init_disabled = false                 # 初始化完成后可设为 true
#[[unsafe.bindings]] login_limiter     # 可选，登录限流
```
